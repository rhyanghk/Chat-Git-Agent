# 执行端安装

不运行脚本，直接复制文件。

## 推荐目录

在你的用户目录建立一个固定文件夹，例如：

```text
~/.chat-git-agent/
```

把本目录内容复制成：

```text
~/.chat-git-agent/
├─ AGENTS.md
└─ 角色/
   ├─ ARCHITECT.md
   ├─ BUILDER.md
   ├─ RESEARCH.md
   ├─ REPAIR.md
   ├─ VERIFIER.md
   └─ RELEASE.md
```

以后聊天端给执行端的启动提示，直接指向这些固定文件。

如果某个执行工具支持自己的全局规则文件，也可以让它的全局规则只写一句：先读 `~/.chat-git-agent/AGENTS.md`。不要再复制一整套规则。

## 项目里不安装这些文件

不要把 `AGENTS.md` 或 `角色/` 复制到业务项目。

业务项目只保存聊天端根据真实项目生成的 `.ai/` 和业务本身的代码、配置、文档。

## 更新

本项目发布新版时，替换用户目录里的 `AGENTS.md` 和 `角色/` 即可。业务项目的 `.ai/` 不需要因为执行端规则更新而重装。
