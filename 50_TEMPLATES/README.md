# 50_TEMPLATES

可复用的正式模板层。模板定义固定字段和精确编号；不复制完整历史，也不创建防御性记录。

| 模板 | 用途 |
| --- | --- |
| HUMAN_WORKSPACE_BOOTSTRAP.md | 首次搭建 workspace。 |
| CHAT_PROJECT_BOOTSTRAP.md | 建立平台 Chat 协作控制项目。 |
| TASK_RECORD.md | 创建编号化正式任务。 |
| GITHUB_RELAY_TASK.md | 创建使用 GitHub 中继的任务。 |
| RESULT_REPORT.md | 输出执行角色正式报告。 |
| CHANGE_REQUEST.md | 请求 scope、revision、角色或基线变化。 |
| bootstrap_check_request.md | 只执行启动检查。 |
| capability_self_check.md | 盘点能力，不产生授权。 |
| architect_handoff_check.md / architect_handoff_transaction.md | 架构师交接。 |
| pointer_response.md | 返回正式资料位置。 |
