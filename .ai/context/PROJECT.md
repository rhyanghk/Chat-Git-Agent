## 用途

提供一套简单的人与人工智能执行工具长期协作规则：聊天端负责安排和验收，执行端按明确任务工作，业务项目用自身 `.ai/` 保存以后继续工作所需的项目事实。

## 已确认的长期限制

- 文档优先使用通俗简体中文。
- 聊天规则只安装在聊天端。
- 执行规则只安装在执行端用户目录。
- 业务项目零预装；第一次接入后由聊天端建立 `.ai/`。
- GitHub 只用于同步和版本记录；不用 GitHub 也要能完成任务。
- 新项目应能跟随 `youling/ai-use` 的实际规则变化，但不能自动推翻上述固定边界。

## 主要入口

- `README.md`
- `聊天端/CHAT_CORE.md`
- `执行端/AGENTS.md`
- `项目接入/第一次接入.md`
- `维护/跟随原项目更新.md`
