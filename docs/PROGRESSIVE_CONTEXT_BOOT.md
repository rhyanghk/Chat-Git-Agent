# Progressive Context Boot

**Classification: L2 Targeted Reference.**

使用 L0 → L1 → L2 → L3 的逐层读取。同步完整项目仓库不等于把全部文件加载进模型上下文。

1. L0：当前执行规则或控制角色最小项目指令。
2. L1：精确编号任务、当前角色和任务列出的项目文件。
3. L2：仅在 GitHub 中继、恢复、交接、冲突、验证、安全或权限场景读取相应协议。
4. L3：历史、理念、案例和被替代材料默认不读。

若 L1 不足以安全工作，报告缺失或 BLOCKED；不要以可能有用为由扫描全部项目、全部历史或所有任务。
